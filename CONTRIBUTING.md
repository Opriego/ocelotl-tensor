# Contributing

Bug reports, feature requests, design discussions, and review feedback are
welcome. Please open an issue before proposing source changes.

External source-code contributions are not currently accepted unless they are
covered by a separate written contributor agreement with the project
copyright holder. This policy preserves the copyright holder's ability to
offer alternative commercial licenses for the compiler code.

No contributor agreement is provided by this repository at this time.
